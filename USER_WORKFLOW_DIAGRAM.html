📋 Workflow Summary:
• Entry Point: Users authenticate via the Login page
• Regular Users: Access Home, Events, Feedback, and Help sections
• Admin Users: Access restricted Admin Dashboard with user management, event management, feedback review, and analytics
• Auth Guards: RequireAuth protects regular user routes, RequireAdmin protects admin routes
